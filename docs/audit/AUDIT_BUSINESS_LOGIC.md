# Аудит бизнес-логики маркетплейса

## Отсутствующие ключевые функции

### Управление инвентарем
- Нет автоматического списания товаров при заказе
- Отсутствует резервирование товаров в корзине
- Нет уведомлений о заканчивающемся товаре
- Отсутствует история изменений остатков

### Модерация и качество
- Нет модерации новых товаров
- Отсутствует система жалоб на товары/продавцов
- Нет проверки качества фотографий
- Отсутствует автоматическая модерация контента

### Финансовая логика
- Нет системы комиссий маркетплейса
- Отсутствует split-платежи между продавцами
- Нет учета налогов
- Отсутствует система возвратов денег

### Уведомления
- Нет email/SMS уведомлений
- Отсутствуют push-уведомления
- Нет уведомлений о статусе заказа
- Отсутствуют маркетинговые рассылки

### Аналитика и отчеты
- Нет аналитики продаж
- Отсутствуют отчеты для продавцов
- Нет рекомендательной системы
- Отсутствует A/B тестирование

## Технические долги

### Транзакции
- Отсутствуют database transactions
- Нет обработки race conditions
- Отсутствует idempotency

### Кэширование
- Нет кэширования популярных товаров
- Отсутствует CDN для изображений
- Нет кэширования в Redis

## Рекомендации по приоритетам

### Высокий приоритет
1. Система управления инвентарем
2. Транзакции БД
3. Базовые уведомления
4. Модерация товаров

### Средний приоритет
1. Финансовая логика с комиссиями
2. Аналитика продаж
3. Кэширование
4. Система возвратов

### Низкий приоритет
1. Рекомендательная система
2. A/B тестирование
